## 🎯 技術的なアピールポイント（C++実装における設計の工夫）

### 1. GAS (Gameplay Ability System) を用いたスケーラブルな能力・属性管理
ゲーム規模の拡大を見据え、キャラクターのスキルやステータス管理にUE標準のフレームワークであるGASを導入しています。
- **Fatクラスの回避**: ダメージ処理やスキル発動ロジックをキャラクタークラスに直接書くのではなく、`GameplayAbility` としてカプセル化することで、Characterクラスの肥大化を防いでいます。
- **属性管理**: `CombatAttributeSet` などを定義し、HPや攻撃力などのステータスをコンポーネントベースで安全に管理・操作できる仕組みを構築しました。

### 2. ネットワークマルチプレイへの対応と適切な権限管理 (Replication / RPC)
オンラインマルチプレイ（クライアント・サーバーモデル）を前提としたネットワーク同期処理をC++で実装しています。
- **サーバー権限（Authority）の徹底**: ダメージ計算、ステータスの増減、死亡判定など、ゲームの進行に関わる重要なロジックは必ずサーバー側（`HasAuthority()`）で処理し、チートや同期ズレを防ぐ堅牢な設計を心がけています。
- **RPCの適切な使い分け**: クライアントからサーバーへの処理要求には `Server` RPC、エフェクトやアニメーション再生などの演出面には `NetMulticast` を用いるなど、通信帯域を意識した使い分けを行っています。
- **変数のレプリケーション**: `GetLifetimeReplicatedProps` 等を用いて、全クライアント間で同期が必要な変数のみを適切にレプリケーションしています。GASの機能と連携させることで、遅延（ラグ）を感じさせないクライアント予測（Prediction）にも対応しやすい基盤を作りました。
